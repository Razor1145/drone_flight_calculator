# Drone Flight Calculator

This project calculates a commercial drone's active flight time based on payload weight and can generate a table of flight times for different payloads.

## AI-Use Disclosure

Used GitHub Copilot inline suggestions while writing the calculator functions and GitHub Copilot Chat `/tests` to generate the initial pytest test suite. I reviewed the suggestions, rejected incorrect code, edited inaccurate output documentation from seconds to minutes, and verified the final code manually. I also reviewed the generated tests and confirmed that all 18 tests pass with pytest.
